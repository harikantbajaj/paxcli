# Code of Conduct

This project follows the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful, assume good faith, and keep discussions technical. Harassment, personal attacks, and bad-faith behavior are not tolerated.

Report issues to **harikant@processflows.ai**. Maintainers may warn, temporarily restrict, or permanently ban contributors who violate these standards.
